# Standard di Progetto: Regola della Sezione Aurea (φ = 1.618)

Questa regola è PERMANENTE e VINCOLANTE per questo workspace e per tutte le sessioni:

Tutti i componenti, le sezioni, le spaziature, la tipografia e i layout devono rispettare matematicamente il Golden Ratio (φ = 1.618):
1. **Tipografia Aurea**: progressione 10px -> 12px -> 16px -> 26px -> 42px -> 68px -> 110px.
2. **Spaziature Auree**: gap, padding e margini scalati con i token `phi-1` ... `phi-7`.
3. **Golden Rectangle (1 : 1.618)**: per tutte le card e i box contenitori.
4. **Divisione Layout 61.8% / 38.2%**: per le composizioni asimmetriche e bilanciate.
